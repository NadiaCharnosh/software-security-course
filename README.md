# Безпека програмного забезпечення

Навчально-методичний комплекс дисципліни **«Безпека програмного забезпечення»**
для здобувачів ступеня бакалавра за спеціальністю 121 «Інженерія програмного
забезпечення» (4 курс).

КПІ ім. Ігоря Сікорського · ФІОТ · кафедра інформатики та програмної інженерії
Автор: Соколовський В. В., д-р філософії, ст. викл.

Обсяг дисципліни — 4 кредити ЄКТС / 120 год: 15 лекцій, 6 лабораторних робіт,
2 модульні контрольні роботи, розрахунково-графічна робота, екзамен.

---

## Склад комплекту

| Каталог | Вміст |
|---|---|
| `syllabus/` | Робоча програма (силабус): денна та заочна форми (.docx) |
| `manual/` | Навчальний посібник у двох частинах: Частина 1 «Курс лекцій» (15 лекцій, 45 рисунків), Частина 2 «Лабораторний практикум» (6 ЛР, МКР, РГР, екзамен) |
| `lectures/slides/` | 15 презентацій до лекцій (.pptx) |
| `lectures/handouts/` | 15 конспектів лекцій для роздачі студентам (.docx) |
| `labs/code/` | Репозиторій коду лабораторних робіт (стенди, каркаси завдань, Docker) |
| `labs/handouts/` | 6 методичних вказівок до лабораторних робіт (.docx) |

## Структура курсу (7 розділів)

1. Основи безпеки ПЗ (моделювання загроз, STRIDE, модель порушника)
2. Захищений життєвий цикл розробки (SSDLC, принципи безпечного проєктування)
3. Моделі та механізми розмежування доступу (Белла–ЛаПадули, HRU, RBAC/ABAC)
4. Ідентифікація, автентифікація та авторизація
5. Прикладна криптографія (симетрична, асиметрична, ЕЦП, PKI)
6. Вразливості програмного коду (OWASP Top 10, безпека пам'яті)
7. Верифікація захищеності (SAST/DAST/SCA, DevSecOps, ланцюг постачання)

## Лабораторний практикум

Код лабораторних робіт — у `labs/code/`. Розгортання стенда:

```bash
cd labs/code
cp .env.example .env        # вкажіть свій номер варіанта
docker compose up -d
```

Параметри індивідуального завдання за номером у списку групи:

```bash
python -m common.variants <N> --lab <1..6>
```

> ⚠️ **Застереження щодо лабораторної роботи 5.** Каталог `labs/code/lab05_vulnapp/`
> містить **навмисно вразливий** навчальний застосунок. Він призначений ВИКЛЮЧНО для
> роботи в ізольованому середовищі Docker Compose. Заборонено запускати його поза
> контейнером, публікувати порт за межі `127.0.0.1` чи розгортати на доступному з
> мережі вузлі. Несанкціоноване втручання в чужі системи — кримінальне правопорушення
> (ст. 361–363-1 Кримінального кодексу України). Усі дані у стенді синтетичні.
