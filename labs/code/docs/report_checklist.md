# Чек-лист самоперевірки звіту про лабораторну роботу

- [ ] Титульний аркуш за зразком (додаток А Частини 2).
- [ ] Зазначено номер і формулювання індивідуального варіанта.
- [ ] Теоретичні відомості обґрунтовують рішення, а не переказують лекцію.
- [ ] Наведено структурну схему та ключові фрагменти коду з поясненнями.
- [ ] Результати експериментів із вхідними даними та покроковою верифікацією.
- [ ] Аналіз результатів: інтерпретація, порівняння з очікуваним.
- [ ] Висновки — конкретні твердження про досягнутий результат.
- [ ] Посилання на репозиторій із зазначенням коміту.
- [ ] Для ЛР5: доказ експлуатації + виправлення + регресійний тест на кожну вразливість варіанта.
- [ ] Зазначено факт та обсяг використання генеративних інструментів (за наявності).
