# Навчальний вразливий застосунок «Документообіг»

**Лабораторна робота 5.** Застосунок містить **13 навмисних вразливостей** і
призначений виключно для роботи в ізольованому середовищі Docker Compose.

> ⚠️ Заборонено запускати поза контейнером, публікувати порт за межі `127.0.0.1`,
> розгортати на віддаленому вузлі чи в мережі Університету. Несанкціоноване
> втручання в чужі системи — кримінальне правопорушення (ст. 361–363-1 КК України).

## Запуск

З кореня репозиторію курсу:

```bash
docker compose up -d
# застосунок:        http://127.0.0.1:8080
# внутрішня служба:  доступна лише зсередини мережі стенда (ціль для SSRF)
```
