# Репозиторій коду до лабораторного практикуму «Безпека програмного забезпечення»

КПІ ім. Ігоря Сікорського, ФІОТ, кафедра ІПІ. Спеціальність 121, 4 курс.

> ⚠️ Каталог `lab05_vulnapp/` містить НАВМИСНО ВРАЗЛИВЕ програмне забезпечення.
> Запускати лише в ізольованому середовищі Docker Compose. Заборонено публікувати
> порти за межі `127.0.0.1` та застосовувати вивчені техніки до сторонніх систем
> (ст. 361–363-1 Кримінального кодексу України).

## Структура

| Каталог | Лабораторна робота |
|---------|--------------------|
| `common/` | генератор індивідуальних завдань (`python -m common.variants <N>`) |
| `lab01_threat_model/` | ЛР1. Модель загроз: шаблони DFD, реєстру ризиків, калькулятор CVSS |
| `lab02_access_control/` | ЛР2. Розмежування доступу: каркас диспетчера + навчальний приклад (модель Белла–ЛаПадули) |
| `lab03_auth/` | ЛР3. Автентифікація: формула Андерсона, каркас паролів, TOTP |
| `lab04_crypto/` | ЛР4. Криптографія: навчальний RSA, каркас AEAD |
| `lab05_vulnapp/` | ЛР5. Вразливий вебзастосунок (13 вразливостей) |
| `lab06_cicd/` | ЛР6. Конвеєр CI/CD: SAST, SCA, SBOM, quality gate |

## Початок роботи

```bash
cp .env.example .env          # вкажіть свій номер варіанта (1–30)
python -m common.variants 7   # параметри вашого варіанта для всіх робіт
```

## Розгортання вразливого стенда (ЛР5–ЛР6)

```bash
docker compose up -d          # http://127.0.0.1:8080 (лише локально)
docker compose down -v        # зупинення й очищення
```

## Тести

Готові тести постачаються для навчального прикладу ЛР2 та навчальної реалізації RSA (ЛР4).
Власні тести здобувач додає до каталогу `tests/` відповідної роботи.

```bash
cd lab02_access_control && pip install -r requirements.txt && PYTHONPATH=. pytest tests/
cd lab04_crypto         && pip install -r requirements.txt && PYTHONPATH=. pytest tests/
```

## Академічна доброчесність

Кожна робота має 30 індивідуальних варіантів: параметри завдання визначає генератор
`common/variants.py` за номером у списку групи. Навчальний приклад ЛР2 побудовано на моделі,
якої немає серед варіантів, тому його використовують як зразок структури, а не розв'язку.
